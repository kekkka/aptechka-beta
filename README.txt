АПТЕЧКА BETA — REACT + TYPESCRIPT

Локально: http://127.0.0.1:8765/

Вход
При открытии появляется выбор из трёх аккаунтов:
— Пациент: Нина Петровна. Крупный интерфейс и отметки собственных приёмов.
— Сиделка: Елена. План, отметки, проверка сигналов и журнал.
— Менеджер лечения: Анна. Назначения, импорт, аптечка и координация заботы.
Нажатие на аккаунт сразу открывает приложение. Логин и пароль не нужны.
Кнопка профиля возвращает к выбору аккаунта. После перезагрузки выбор
показывается снова. Данные лечения сохраняются при смене роли.

Запуск
Требуется Node.js 22.12+ (или 20.19+).
  npm install
  npm run dev
Также поддерживается pnpm install / pnpm dev; pnpm-lock.yaml зафиксирован.
На этом компьютере можно выполнить ./start-local.sh — он также находит
Node.js из установленного окружения Codex, если node отсутствует в PATH.

Проверки и сборка
  npm test          — 37 тестов логики лечения, демо и отчёта для врача
  npm run build    — строгая проверка TypeScript и сборка Vite в dist/
Готовую сборку можно открыть статическим сервером:
  python3 -m http.server 8765 --bind 127.0.0.1 --directory dist

Структура
src/Login.tsx               — выбор аккаунта
src/App.tsx                 — экраны, навигация и действия
src/ImportPrescription.tsx  — React-флоу импорта и проверки назначения
src/model.ts, types.ts      — типизированная логика и данные
src/parser.ts, reader.ts    — разбор текста и локальный OCR/PDF
src/components.tsx          — общие элементы и доступные диалоги
public/vendor/              — локальные Tesseract.js, PDF.js и языковые модели

Пациент
— Свайп подтверждает приём без дополнительного окна.
— Барабан показывает предыдущий, текущий и следующий приём.
— Через час без отметки приём получает статус «Не принято».
— Демо-время меняется по шкале после нажатия «Перейти»; отметки сохраняются.
— В часовом окне приёма можно явно сбросить только его отметку.
— «Позвонить близким» открывает список контактов.
— «Показать врачу» открывает историю за сегодня, 7 или 30 дней:
  сводка, просмотр по дням и препаратам, авторы и время отметок.
  За прошлые дни без записей показано «Нет данных».
— Для будущих графиков показателей предусмотрен отдельный раздел.

Публикация
GitHub Actions устанавливает зависимости из lock-файла, запускает тесты,
проверяет TypeScript, собирает Vite и публикует dist на GitHub Pages.
Пути ресурсов относительные: сайт работает и в подкаталоге репозитория.

Данные
Сохранён прежний ключ localStorage aptechka_family_mobile_v1: существующие
курсы, отметки и домашний запас доступны после переноса.
Выбор аккаунта демонстрационный. Серверная авторизация, синхронизация,
push, SMS и телефония пока не подключены. Роли работают в одном браузере.
Фото/PDF и исходный текст обрабатываются в памяти вкладки; после импорта
сохраняется только проверенный план. OCR может ошибаться: каждый препарат
требует сверки с оригиналом. Переменные и сложные схемы автоматически
не запускаются. Поддерживаются ежедневные таблетки/капсулы до 90 дней,
до 8 времён приёма и до 8 препаратов в курсе.

Перед переносом исходная версия сохранена в .migration-backup/.
