ПУБЛИКАЦИЯ АПТЕЧКИ НА GITHUB PAGES

1. Создайте репозиторий на GitHub. Для бесплатного GitHub Pages используйте public.
2. Загрузите содержимое этой папки в корень репозитория, в ветку main.
   Важно: включите скрытую папку .github с файлом workflows/pages.yml.
3. Откройте Settings → Pages → Build and deployment → Source → GitHub Actions.
4. В Actions запустите Publish GitHub Pages → Run workflow, если публикация
   не стартовала автоматически после загрузки файлов.
5. После успешного deploy адрес появится в Settings → Pages и в запуске workflow.
   Обычно адрес имеет вид https://LOGIN.github.io/REPOSITORY/.

Исходники сайта находятся во frontend/ (Vite + React). Копировать их в
корень не нужно: workflow устанавливает зависимости, запускает тесты,
собирает сайт и публикует frontend/dist. API-ключи и секреты не требуются.
Обновления main запускают новую проверку и публикацию.

Это мобильный прототип. OCR выполняется на устройстве; записи хранятся
локально в браузере. Аккаунты, синхронизация и фоновые push не подключены.
Новый адрес сайта имеет отдельное хранилище: локальные записи с localhost
или предыдущего домена автоматически туда не переносятся.

Локальная проверка из папки frontend:
npm ci
npm test
Локальный запуск: npm run dev
Открыть http://127.0.0.1:8765/
